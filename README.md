# 📝 Mehrsprachige ToDo-Webanwendung (PWA)

## 📖 Projektbeschreibung
Entwicklung einer mehrsprachigen ToDo-Webanwendung als **Progressive Web App (PWA)** mit HTML, CSS und JavaScript.

Das Projekt dient als praxisnahes Beispiel für einen vollständigen Softwaretestprozess. 

## 🔄 Testprozess & Umfang
Dieses Projekt deckt den gesamten Lebenszyklus moderner Qualitätssicherung ab:
- 📋 **Anforderungsanalyse & Testplanung**
- 🧠 **Testfalldesign**
- 🧪 **Manuelle und automatisierte Tests** (unter Einsatz von *Playwright*)
- 🐛 **Fehlerdokumentation**
- ⚙️ **CI/CD-Pipeline** (Aufbau und Nutzung mit *GitHub Actions*)

## 🤖 KI-Integration
Künstliche Intelligenz (KI) wird in diesem Projekt aktiv zur Unterstützung bei der Entwicklung, dem Testdesign sowie der Erstellung der Dokumentation eingesetzt.

## 🛠️ Technologien & Features
- **Frontend:** HTML, CSS, JavaScript
- **PWA:** Service Worker, Web App Manifest (Offline-Fähigkeit, Installierbarkeit)
- **Test-Automation:** Playwright
- **CI/CD:** GitHub Actions
